      From a source update to a reviewable answer.
      The live pipeline collects official records, keeps document versions and retrieves passages with SQLite FTS5 / BM25. A local model writes a short answer with exact source quotations. Failed checks stay failed; no recording is substituted for a live result.
      ComponentDepends onProduces / enforces
      Live connectorsEIA RSS, Federal Register API, OFAC HTMLConditional HTTP requests, provider cooldowns, response limits and visible source errors
      Version storeValidated source documentsAppend-only captures, fingerprints and diffs; publication and fetch dates stay separate
      RetrievalLatest stored versions + user-selected scopeBM25-ranked passages with document/version IDs; no-match abstention
      AI briefQuestion + retrieved passages + structured-output modelQuote and numeric validation, visible failures, reviewable interpretation — no automatic publication
      Job workerLocal API + SQLite checkpointsResponsive progress, one-job backpressure, cancellation and restart recovery to an interrupted state
      The separate recorded case remains a reproducible regression lab. Live coverage is publisher summaries, abstracts and license titles, not every full document. Lexical retrieval can miss relevant passages, and citation matching cannot prove semantic correctness. Public multi-user hosting requires authentication and a deployed backend.
